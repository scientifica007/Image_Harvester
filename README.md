# Image Harvester v0.1.1 — حصّاد الصور

تطبيق لسطح مكتب Ubuntu/Linux لاستخراج صور صفحات الويب والمواقع **فقط**، دون حفظ نسخ من صفحات المواقع. مصمم ليعمل على أجهزة ذات موارد محدودة، ويستخدم Python القياسي وGTK3/Pango دون Playwright أو Chromium.

## الواجهة العربية

تُعرض العربية عبر GTK3/Pango باتجاه RTL أصلي، بينما تبقى روابط المواقع ومسارات الملفات LTR، دون قلب النصوص يدويًا.

## إمكانات الإصدار

- وضع **صفحة واحدة** أو **موقع كامل ضمن حدود** (يتتبع الروابط الداخلية، ولا يعبر إلى مواقع خارجية في الزحف).
- اكتشاف الصور من `img`, `picture/source`, `srcset` وسمات lazy الشائعة وCSS و`@import` وOpenGraph وصور الروابط المباشرة.
- تنزيل صور JPEG/PNG/GIF/WebP/SVG/AVIF/BMP/ICO/TIFF/HEIC عند التعرف على توقيع المحتوى، بغض النظر عن امتداد الرابط.
- منع الحفظ المزدوج بالاعتماد على SHA-256؛ تنزيل متسلسل مع تأخير وضبط حدود السرعة والحجم والعدد والعمق.
- احترام `robots.txt` للموقع ولأي مصدر صور خارجي؛ التوقف الآمن وتقارير `manifest.json` و`images.csv`.
- لا حساب ولا تتبع للمستخدم ولا إرسال إلى أي خادم تابع للتطبيق.

## التثبيت على Ubuntu 24.04 LTS (الخيار الأسهل)

1. نزّل `image-harvester_0.1.1-1_all.deb`.
2. افتح الطرفية في المجلد الذي يحتوي على الملف (عادة `~/Downloads`):

   ```bash
   cd ~/Downloads
   sudo apt install ./image-harvester_0.1.1-1_all.deb
   ```

3. شغّل التطبيق من قائمة التطبيقات باسم **حصّاد الصور** أو من الطرفية:

   ```bash
   image-harvester
   ```

`apt` يثبّت GTK3/PyGObject عند الحاجة ولا حاجة إلى `pip`. لا يؤثر ذلك في HTTrack المثبت مسبقًا.

## التشغيل من المصدر دون تثبيت حزمة .deb

```bash
sudo apt install python3-gi gir1.2-gtk-3.0
unzip Image-Harvester-v0.1.1-source.zip
cd Image-Harvester-v0.1.1
./bin/run-local.sh
```

يمكن تشغيل الاختبارات دون شبكة خارجية:

```bash
python3 -m unittest discover -s tests -v
```

## الاستعمال

1. الصق عنوان صفحة ويب أو موقع كامل، مثل `https://example.com/gallery`.
2. اختر **صفحة واحدة** أو **موقع كامل**.
3. اختر مجلد تنزيل (افتراضيًا `~/Downloads/ImageHarvester`).
4. إذا اخترت موقعًا كاملًا، اضبط عدد الصفحات وعمق التتبع؛ اترك القيم المحافظة أول مرة.
5. اضغط **بدء الاستخراج**. عند الانتهاء اضغط **فتح مجلد النتائج**.

**مجلد الحفظ:** تنشأ مجلدات مؤرخة لكل تشغيل تحتوي `images/` فقط للصور، وملفين لإحصاءات وقائمة التنزيلات. لا تُخزن صفحات HTML/CSS.

**مفهوم الموقع الكامل:** يبحث ضمن الموقع وصولًا إلى عدد الصفحات وعمق الروابط المحددين، وليس مسحًا سحريًا لكل الصور على خادم الموقع.

**ملاحظة مهمة:** لا يشغّل الإصدار 0.1 JavaScript ولا يستعمل جلسة المتصفح أو ملفات تعريف الارتباط؛ الصور التي يولّدها الموقع ديناميكيًا بعد النقر قد لا تُكتشف. لصور المواقع المحمية بحساب أو غير المرتبطة علنًا، لا يتخطى التطبيق قيود الوصول.

**الأمن وحقوق الاستخدام:** لا تنزّل أو تعِد نشر صورًا لا تملك حق استعمالها. احترم شروط الموقع، ولا تفتح ملفات SVG مجهولة المصدر بأدوات تعرض محتوى نشطًا. الطلبات تُرسل إلى العناوين المضمّنة في الصفحات وملفات CSS المرتبطة بها؛ قد تكون على خوادم أخرى.
