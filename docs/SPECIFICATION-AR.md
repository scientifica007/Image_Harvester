# Image Harvester — المواصفات التقنية المعتمدة v0.1.0

**المنصة:** Ubuntu 24.04 LTS / GNU/Linux مع Python 3.12+ وTk 8.6.  
**النوع:** تطبيق محلي لسطح المكتب، مجاني ومفتوح المصدر، دون خادم سحابي.  
**هدف المنتج:** استخراج وتنزيل ملفات الصور القابلة للاكتشاف من صفحة ويب واحدة أو من صفحات موقع واحد، دون حفظ نسخ صفحات HTML أو الصور المكررة.

## 2. اكتشاف الصور «غير المعروضة»

المقصود في هذا الإصدار الصور المُشار إليها في HTML/CSS لكنها غير مرئية بسبب موضع التمرير أو إخفاء عنصر أو Lazy Load الذي تضع الصفحة عنوانه في مصدر HTML. التطبيق **لا يستطيع** اكتشاف الملفات المجهولة أو الموجودة خلف واجهات JavaScript الديناميكية دون تشغيلها، ولا يحاول تخمين أسماء الملفات أو تجاوز أذونات الخوادم.

## 3. التصميم التقني

- **واجهة:** Tkinter / ttk، العربية لغة العرض، مع حقول مسارات وروابط مكتوبة لاتينيًا؛ Tk لا يوفر محاذاة RTL كاملة.
- **محرك HTTP:** `urllib.request` القياسي. تنزيل متسلسل 1 اتصال فعلي في كل لحظة لتقليل استهلاك الموارد والحمل على الخوادم.
- **المحلل:** `html.parser.HTMLParser` + تعبيرات منتظمة محدودة لـCSS. لا يعتمد على متصفح مدمج.
- **التزام الوصول:** `urllib.robotparser` على مستوى كل مضيف، والامتناع عن التنزيل إذا تعذر تحديد سماح robots (باستثناء غياب الملف 404/410).
- **التخزين:** ملف `.part` مؤقت مع بث 64KiB لكل دفعة، SHA-256 وتسمية آمنة، وتقرير محلي JSON وCSV.
- **التزامن:** عامل خلفي واحد + `queue.Queue` لتحديث الواجهة. لا تجري عمليات HTTP داخل خيط الواجهة.
- **الشبكة:** لا يوجد إرسال بيانات لخدمة تخص التطبيق، ولا جمع إحصاءات استخدام، ولا مفاتيح API. تُرسل الطلبات إلى الموقع الذي حدده المستخدم ومصادر الصور/الأنماط المرتبطة به وملفات robots الخاصة بها.

## 4. حدود التشغيل الافتراضية

| الضابط | الافتراضي | المجال |
|---|---:|---:|
| عدد صفحات الموقع | 50 | 1–500 |
| عمق التتبع | 2 | 0–6 |
| روابط الصور الفريدة المكتشفة | 300 | 1–3000 |
| أقصى حجم لصورة واحدة | 15 MiB | 1–100 MiB |
| أقصى مجموع للملفات المحفوظة | 250 MiB | 1–5000 MiB |
| الفاصل الزمني الأدنى بين الطلبات | 0.35 ثانية | 0–10 ثوانٍ |
| مهلة اتصال المورد | 12 ثانية | 2–120 ثانية (12 في الواجهة) |
| حجم صفحة HTML للمعالجة | 4 MiB | ثابت |
| حجم ملف CSS للمعالجة | 1 MiB | ثابت |
| عدد ملفات CSS | 60 | ثابت |

لا يضمن إجمالي 250MiB أن الاستهلاك المؤقت للحفظ لا يتجاوز الحد لحظيًا بمقدار ملف `.part` واحد صغير نسبيًا، ويُحذف هذا الملف عند الفشل أو الإيقاف.

## 5. تنظيم مخرجات كل عملية

```text
~/Downloads/ImageHarvester/
  example_com_20261010_090000/
    images/
      00001-photo-<hash>.jpg
      00002-banner-<hash>.png
    manifest.json
    images.csv
```

`manifest.json` يوثق إعدادات العملية وإحصاءاتها وحالة الإيقاف وروابط المصدر والبصمات. `images.csv` جدول سهل الفرز. **لا تُحفظ صفحات HTML أو ملفات CSS.**

## 6. القيود والخصوصية

1. التطبيقات أحادية الصفحة SPA والمواقع المعتمدة كليًا على JavaScript قد تنتج صفر صور، مع أنها تعرض صورًا في المتصفح.
2. `srcset` معقد أو أنماط CSS غير قياسية أو صور Base64 المضمّنة قد لا تُستخرج.
3. لا يحاول التطبيق الدخول إلى المواقع المحمية أو استعمال ملفات Cookies الشخصية أو تجاوز مكافحة الروبوتات.
4. الصور التي تُنزَّل هي بيانات خارجية غير موثوقة؛ لا تفتح ملفات SVG من مواقع غير موثوقة في أدوات تنفّذ محتوى نشطًا.
5. يحتاج المستخدم إلى الالتزام بحقوق النشر وشروط الخدمة وسياسات الموقع؛ التنزيل لا يمنح ترخيصًا بإعادة النشر.
6. يمكن أن يشير الموقع إلى نطاقات صور خارجية؛ ستُطلب هذه الموارد عند اكتشافها ما لم تمنعها robots.
7. لا يحتفظ التطبيق بقاعدة بيانات عامة لتاريخ العمليات، لكن ملف التقرير يحتوي روابط قد تتضمن معرّفات؛ لا تشارك التقارير بلا مراجعة.
8. لا يحفظ ملفات صفحات HTML في مجلد الصور؛ تقارير JSON وCSV استثناءات لازمة لتوثيق النتائج.

## 7. معايير القبول

- **AC-01:** رابط محلي صالح ينتج صورة صحيحة ومجلد نتائج.
- **AC-02:** وضع صفحة واحدة لا يتتبع روابط صفحات أخرى.
- **AC-03:** وضع الموقع يتبع الروابط ضمن المضيف والعمق والعدد المحدد.
- **AC-04:** يتم اكتشاف سمات lazy وsrcset وCSS.
- **AC-05:** محتوى غير صورة مموه بامتداد صورة يُرفض.
- **AC-06:** صورتان لهما البايتات نفسها تحفظان مرة واحدة.
- **AC-07:** موارد robots الممنوعة لا يتم تنزيلها.
- **AC-08:** زر الإيقاف لا يترك ملفات `.part` ولا يمنع إنشاء تقرير.
- **AC-09:** تعمل الواجهة على جهاز Ubuntu 24.04 مع `python3-tk` دون متصفح إضافي.
- **AC-10:** الحزمة `.deb` تسجل أمر `image-harvester` وقائمة التطبيقات.
