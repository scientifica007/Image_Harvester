# Image Harvester v0.1.1 — حصّاد الصور

**أول إصدار معتمد ميدانيًا على Ubuntu 24.04 LTS.**

## الوظائف المعتمدة
- واجهة عربية GTK3/Pango، واتجاه RTL، والروابط والمسارات باتجاه LTR، مع الأيقونة المعتمدة.
- استخراج الصور من صفحة واحدة أو موقع كامل ضمن حدود اختيارية.
- مراعاة `robots.txt` وكشف التكرارات وتقارير JSON/CSV.
- حزمة `image-harvester_0.1.1-1_all.deb` متاحة ضمن أصول الإصدار.

## القبول الميداني — 2026-10-10
- تجربة بملف نتائج: صفحة واحدة، **74 مكتشفة، 74 محفوظة، صفر أخطاء، و7 موارد تجاوزها robots.txt**.
- تجربة أخرى مصورة: **300 مكتشفة، 299 محفوظة، صورة مكررة واحدة، صفر أخطاء**.

## ملاحظات معلنة
- يحفظ `manifest.json` رقم المحرك `0.1.0` حاليًا، رغم ظهور `0.1.1` في الواجهة؛ سيُعالج ذلك في إصدار لاحق.
- لا يُشغّل JavaScript، وقد تُحفظ أيقونات الموقع ضمن الصور.
- لا يتضمن الإصدار صورًا من Getty Images أو من مواقع الغير؛ استخدامها يخضع لحقوق أصحابها.
